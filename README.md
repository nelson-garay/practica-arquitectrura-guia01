## Descripción del curso

Este curso tiene como finalidad desarrollar conocimientos y habilidades relacionados con el uso de herramientas tecnológicas y plataformas de desarrollo, especialmente Git y GitHub. A través de actividades prácticas, se busca comprender el manejo de repositorios, el control de versiones y la organización de proyectos, así como adquirir buenas prácticas para el desarrollo y la colaboración en proyectos de software.

Durante el curso se trabajará de manera progresiva, comenzando con los conceptos fundamentales y avanzando hacia el uso de herramientas que permitan gestionar, documentar y compartir proyectos de manera organizada.

## Expectativas del estudiante

Como estudiante, espero adquirir los conocimientos necesarios para utilizar Git y GitHub de manera correcta y autónoma. Mi principal expectativa es aprender a crear y administrar repositorios, realizar cambios y mantener un historial organizado de mis proyectos.

Asimismo, espero desarrollar habilidades que me permitan trabajar de manera más ordenada en futuros proyectos de programación, comprender el control de versiones y utilizar GitHub como una herramienta para almacenar, documentar y compartir mis trabajos.

También espero fortalecer mi capacidad para trabajar en proyectos colaborativos y familiarizarme progresivamente con las herramientas utilizadas actualmente en el desarrollo de software.
